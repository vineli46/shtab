Подключить ИИ-мозг

С ним Джарвис поймёт любой вопрос, а не только команды. Настройка один раз, 3 минуты, бесплатно:

  1. Откройте openrouter.ai → кнопка «Sign in» → «Continue with Google» — войдите своей почтой.
  2. Откройте страницу ключей → «Create API Key» → любое имя → «Create» → скопируйте ключ (начинается с sk-or-).
  3. Вставьте ключ в поле ниже и нажмите «Сохранить».

Ключ хранится только в этом браузере, посетители страницы его не видят. Бесплатного лимита хватает на десятки вопросов в день.

Умный и быстрый мозг Сбера — для мака, бесплатно 1 млн токенов в месяц (это сотни разговоров), сайт на русском:

  1. Откройте developers.sber.ru/gigachat → «Попробовать GigaChat API» → войдите через Сбер ID.
  2. В личном кабинете создайте проект GigaChat API и скопируйте Authorization Key (длинная строка-ключ).
  3. Вставьте ключ сюда (сидя за маком) и нажмите «Сохранить» — он сохранится на маке, не в браузере.

    Своя связка вместо готового бота MCN за 20 ₽/мин: Voximplant («труба») + Яндекс Realtime (речь-в-речь по-русски, ≈2–4 ₽/мин) + пять функций прямо в ЦРМ. Постоянному клиенту Алёна прямо в приветствии называет его прошлый заказ и адрес (коротко: улица, дом, квартира) и спрашивает «Хотите повторить?» — отдельного вопроса-развилки больше нет. Порядок разговора жёсткий: приветствие → данные из базы → повтор? → подтверждение заявки → самый последний вопрос «Оплата наличными или безналичный расчёт?» → и только потом заказ уходит в ЦРМ; страховка в программе не даст оформить заказ, если оплата не спрошена. «Безналичный» или «картой» без уточнения = карта курьеру; СБП и оплата онлайн — только если клиент сам их назвал. Организация, платившая по счёту, не оформляется — перевод на оператора. Клиента нет в базе — это новый клиент: Алёна молча переводит на оператора, а дежурную фразу «вашего номера в нашей базе нет…» произносит программа. И главное про манеру: Алёна договаривает каждую фразу до конца и не начинает её заново — если клиент заговорил поверх, она ответит следующей репликой. Сценарий залит в Voximplant и сверен с сервером побайтово. Затем версию прожарили 34 агента-критика (проверка по тексту в две волны: поисковики находят, проверщики подтверждают или отклоняют): 26 подозрений, 16 подтвердились, 10 отклонены.
